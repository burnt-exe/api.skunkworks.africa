# **App Name**: EasyDocs

## Core Features:

- Purchase Order Generation: Creation of professional-looking Purchase Orders with company and supplier information.
- Invoice Generation: Generation of invoices, including line items, quantities, and prices.
- Receipt Generation: Creation of receipts.
- Payslip Generation: Generation of payslips.
- Sales Order Generation: Sales order creation functionality.
- AI-Assisted Documentation: AI-powered "tool" that uses user provided business type and VAT to automatically suggest appropriate item descriptions, pricing, and quantities based on common industry standards. This helps expedite the documentation process.
- Document Export: Export documents to various formats (PDF, Word, Excel).

## Style Guidelines:

- Primary color: #3F51B5 (Deep Purple) for main buttons and interactive elements.
- Secondary color: #F44336 (Red) for destructive actions and error states.
- Accent color: #4CAF50 (Green) to indicate success and positive actions.
- Background color: #F5F5F5 (Light Gray) for the main content area to ensure readability.
- Surface color: #FFFFFF (White) for cards and modal backgrounds.
- Body and headline font: 'Roboto', a sans-serif font for a clean and modern look.
- Use Material Design Icons for a consistent and recognizable visual language.
- Maintain a clear and structured layout with sufficient white space for readability.
